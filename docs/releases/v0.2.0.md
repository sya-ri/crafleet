# Crafleet 0.2.0

Adds restart supervision, interactive Modrinth discovery, and support for every Node.js 24 release. Install with `npm install --global crafleet@0.2.0`. CLI supports Node.js 24–26; development requires 24.11.1 or later.

## Supervision

After an explicit start, run `crafleet -C <project> supervise`. Server exits/crashes restart active artifacts offline after ten seconds, at most five attempts in five minutes. Failed readiness or an exhausted budget needs an explicit successful start/restart. Unknown processes, journals, and unsafe locks block progress.

`stop` persists stopped intent across supervisor/host restarts. Maintenance shares the operation lock; failures remain stopped. Supervisor shutdown gracefully stops Java while preserving intent. Automatic launches never apply pending or accept fresh EULA consent.

All runtime operators need 0.2.0 or later to respect intent. Existing projects without intent are not started implicitly. Services should invoke `supervise` directly; unconditional `start` overrides intentional stops. No declaration migration is required.

## Plugin discovery

Source-free `plugins add` opens an interactive Modrinth search and version browser. Scripts, JSON, offline, and multi-project operations use explicit sources. Plugin inspection also accepts Paper-compatible quoted multiline descriptions while preserving strict validation and original bytes.
