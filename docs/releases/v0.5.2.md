# Crafleet 0.5.2

Crafleet 0.5.2 adds persistent console command history and optional server-backed Tab completion, with guided addon installation and official addon management commands.

## Console history and completion

Use Up/Down to recall commands for the current server. Returning to the newest entry restores the input you were editing. Crafleet retains up to 1,000 nonempty commands across console sessions and collapses consecutive duplicates. History works without an addon.

When you open an eligible running server with `crafleet console`, Crafleet offers to install the completion addon. **Not now** is selected by default. **Don't ask again for this server** saves the choice in your user data, outside project configuration; `console --ask-addon` overrides it once. Automated sessions do not install the addon implicitly.

Installation prepares the addon for the next server start or restart and never restarts a running server automatically. After activation, Tab completes commands and arguments at the cursor. With multiple candidates, Tab/Shift+Tab or the arrow keys select a candidate, Enter accepts it, and Esc closes the list. Accepting a candidate does not execute the command.

## Official addons

Inspect available addons and install completion manually with:

```sh
crafleet addons
crafleet addons info console
crafleet addons add console
```

Apply the prepared installation with the normal `start` or `restart` flow. Use `addons update [console]` to prepare the catalog's recommended version and `addons remove console` to prepare removal. Removal preserves addon data and command history. The commands support normal project selection, dry runs, offline operation with cached artifacts, and JSON output. Unsupported targets are reported and skipped; conflicting third-party plugins are not overwritten.

The release includes separate Paper and Velocity JARs with checksums. Crafleet verifies the official artifact and plugin identity before preparing installation.

## Compatibility

| Platform | Minimum supported console addon target | Addon bytecode |
| --- | --- | --- |
| Paper | 1.8.8, including public builds 443, 444, and 445 | Java 8 |
| Velocity | 3.4.0-SNAPSHOT build 507; 3.4.0 stable is also supported | Java 17 |

The server's own Java requirements still apply. Compatibility is limited to the versions in the bundled catalog; `addons info console` shows eligibility and verification status for the selected project. Paper completions come from its public command map; candidates supplied only through console-specific events may differ. See the [console addon guide](https://github.com/sya-ri/crafleet/blob/v0.5.2/addons/console/README.md) for the complete behavior and support policy.

## Upgrade

Install with `npm install --global crafleet@0.5.2`. Node.js 24, 25, and 26 remain supported. No project or backup migration is required. Existing consoles, command sending, and noninteractive JSON sessions remain available without the addon.

Updating the CLI does not reload already-running supervisors or runners. Use the normal graceful maintenance procedure to activate the updated runner before enabling completion. Legacy `config/` projects remain supported through 0.5.x, with removal scheduled for 0.6.0.
