# Crafleet 0.2.1

Fixes a supervision race that could stop healthy Java when another operation released the workspace lock before owner inspection. Election, polling, and shutdown now retry transient contention, including one polling interval for owner publication. Abandoned/malformed locks and duplicate supervisors remain blocked.

Install with `npm install --global crafleet@0.2.1`. Node.js 24–26 remain supported; no declaration or state migration is required. Supervised projects still require all runtime operators to use at least 0.2.0.

Existing supervisors keep their loaded code. Activate the fix through the normal graceful service restart, accounting for Java downtime and preserving running/stopped intent. Installing the CLI alone does not reload them.
