# Crafleet 0.3.1

Adds configurable file discovery and persistent shell completion setup. Install with `npm install --global crafleet@0.3.1`; Node.js 24–26 remain supported.

## Discovery

```yaml
config:
    files:
        - server.properties
        - plugins/MyPlugin/items/**/*.yml
        - "!plugins/MyPlugin/items/generated/**"
```

Ordered runtime-relative globs include/exclude new candidates. Omission keeps standard defaults; a list replaces them; `[]` disables discovery. Managed files remain managed. Missing/non-directory roots yield no candidates; permission and unsafe-link errors remain visible.

`config list --candidates` now shows only unmanaged files; scripts needing managed inventory must use `config list`. `capture --initial` uses discovery, while ordinary diff/capture uses managed files. Register secrets before capture. See the [0.3.1 guide](https://github.com/sya-ri/crafleet/blob/v0.3.1/README.md) for pattern options.

## Completion

`completion install [shell]` previews and confirms persistent Bash/Zsh/Fish/PowerShell setup, preserving custom profile text. Noninteractive installation requires explicit `--yes`. `doctor --shell` checks setup and can offer it interactively; JSON/CI/non-terminal/`--yes`/dry-run diagnosis remains read-only.

## Upgrade order

Existing declarations remain valid without `config.files`. **Upgrade every long-running supervisor to 0.3.1 before adding that field.** A 0.3.0 supervisor rejects the new key while reloading and may stop Java during error shutdown.

Installing a new CLI does not reload supervisors/runners. Preserve files used by running processes, perform the graceful runtime transition, and verify new supervisors before changing declarations.
