# Crafleet 0.5.3

Crafleet 0.5.3 improves console readability and simplifies internal parsing and shared operations. It is a maintenance release with no project or backup format changes.

## Console readability

The selected Tab-completion candidate now appears in bold green. Status messages and completion counts use yellow, keyboard hints use cyan, and separators use gray. When colors are disabled, the selected candidate remains marked with brackets and all status information stays readable.

## Internal improvements

Configuration parsing, console word navigation, shell-profile inspection, POSIX process detection, and macOS permission checks avoid regular-expression backtracking on long input. Existing line boundaries, configuration formatting, and validation rules are preserved.

Shared helpers consolidate terminal sanitization, partial-failure reporting, streaming artifact hashes, manifest source validation, and deployment startup. Bundle checks use the existing AST validation, and unused operation-banner code has been removed. Command behavior and exit codes remain unchanged.

## Upgrade and compatibility

Install with `npm install --global crafleet@0.5.3`. Node.js 24, 25, and 26 remain supported. No project or backup migration is required, and console addon compatibility is unchanged from 0.5.2.

Updating the CLI does not reload already-running supervisors or runners. Use the normal graceful maintenance procedure to activate updated runtime code. Legacy `config/` projects remain supported through 0.5.x, with removal scheduled for 0.6.0.
