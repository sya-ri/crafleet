# Crafleet 0.1.0

The first public release manages Paper and Velocity as reproducible projects: declarations and reviewed configuration in Git, exact artifact locks, and pending updates applied during a managed restart.

## Install and compatibility

```sh
npm install --global crafleet@0.1.0
crafleet --help
```

Requires Node.js 24.20.0 through 26 and the Java version required by your server. Runs on Linux, Windows, and macOS; install it on the server host. Java installation, SSH, and OS services remain external.

Automatic restic setup supports Linux/macOS x64 and arm64 and Windows x64. Restic-backed operations are unavailable on other architectures.

## Main workflows

- Resolve server/plugin JARs from supported providers or local files, verify hashes and descriptor identities, and stage changes without replacing running JARs.
- Capture configuration with three-way comparison and secret references; review conflicts before deployment.
- Manage runtime through start/stop/restart, logs, and a console that detaches without stopping Java. Paper requires explicit EULA consent, remembered per user/home.
- Back up files, SQLite, and InnoDB MySQL/MariaDB to encrypted restic repositories. Shared groups stop all managed writers; external writers must already be stopped and non-loopback SQL connections need a CA.
- Extract snapshots for inspection before applying. Apply takes a pre-restore backup, restores recorded active state, and leaves Java stopped.

The npm package includes the CLI and runner; the repository also provides the agent skill. See the [0.1.0 guide](https://github.com/sya-ri/crafleet/blob/v0.1.0/README.md) and [full history](https://github.com/sya-ri/crafleet/commits/v0.1.0).
