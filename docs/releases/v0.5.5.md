# Crafleet 0.5.5

Crafleet 0.5.5 fixes status-query races that could stop supervision during a server shutdown, including scheduled restarts, and updates bundled dependencies and development tools to their latest stable versions.

The runner now reports `stopping` until it has removed its lifetime guard and persisted its final state. If the runner closes its control connection during a status query, the CLI rereads the final record and accepts `stopped` only for the same runner after its lifetime guard is gone. Mismatched identities, unreachable live runners and uncleared guards still require deliberate inspection and recovery.

Install with `npm install --global crafleet@0.5.5`. Updating the CLI does not replace existing supervisors or runners. Restart the supervisor service during a maintenance window to use the fixed CLI and launch a new runner. Supervisor shutdown gracefully stops Java and preserves runtime intent; supervision resumes the active installation when the service starts again.

Node.js 24, 25 and 26 remain supported. No declaration or runtime data migration is required.

The console uses pi-tui 1.5 while preserving Home for older log history and End for returning to live output. Development now uses pnpm 12 and Vitest 5; benchmark scripts use Vitest's test-context API and JSON reporter output.
